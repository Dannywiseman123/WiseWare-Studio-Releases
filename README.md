# WiseWare Studio releases

Signed update files for WiseWare Studio. The app checks here by itself, downloads new versions and only installs them after checking WiseWare's signature.

## Newest version: 3.0.3

- Alerts now always match the colour theme you pick for a scene pack. Change the theme in Customise and your alerts change with it straight away, in OBS and in every preview, with nothing to reinstall.

**New to WiseWare Studio?** Download [WiseWare-Studio-Starter.exe](https://github.com/Dannywiseman123/WiseWare-Studio-Releases/raw/main/WiseWare-Studio-Starter.exe) (about 6 MB) and run it. It downloads the newest version, checks WiseWare's signature and installs it.

**Already have it?** It updates by itself. You can also press Check for updates in Settings.
